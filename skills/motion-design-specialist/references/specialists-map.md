# Specialists Map

Use this skill alone when the main decision is motion strategy plus implementation.

Pair with another specialist when the bottleneck is elsewhere.

- `ui-ux-specialist`: use when the visual direction, hierarchy or brand language is still undefined.
- `frontend-engineer`: use when motion touches component architecture, state management or framework-agnostic frontend execution.
- `angular-specialist`: use when the codebase is Angular-heavy and the implementation should follow Angular conventions.
- `performance-optimizer`: use when animation budget, frame drops or Core Web Vitals are the main risk.
- `test-engineer` or `playwright-specialist`: use when the motion change needs regression coverage in critical flows.
