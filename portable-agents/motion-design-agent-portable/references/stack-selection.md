# Stack Selection

- CSS only: hover, focus, simple enter and exit, tabs, drawers, modal transitions
- IntersectionObserver plus CSS: reveal-on-scroll, lightweight stagger, section entrances
- Small JS or WAAPI: sequencing, interruptible state changes, runtime-driven motion
- Framework-native motion: when the codebase already uses its own motion primitives
- GSAP or ScrollTrigger: scrubbed storytelling, pinning, synchronized multi-element timelines

Default rule: if a simpler option can achieve the same perceived result, choose the simpler option.
